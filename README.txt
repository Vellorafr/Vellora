VELLORA — FREE STATIC SHOP DEMO

WHAT'S INCLUDED
- Responsive Vellora storefront
- Product catalogue with sample products/prices
- Working add-to-bag, quantity controls and subtotal
- Order-request form that prepares a WhatsApp message

IMPORTANT LIMITATIONS
This is a front-end demo, not a full commerce backend.
- It does NOT process payments or collect card/UPI details.
- It does NOT manage stock, shipping labels, taxes, refunds or customer accounts.
- Orders are manual requests and must be confirmed by the store owner.
- Product names, prices and policies are examples. Replace them before launch.
- Replace STORE_WHATSAPP in script.js with a guardian-managed store number.
- The fonts load from Google Fonts; without internet, fallback fonts are used.

FREE HOSTING
You can host these files as a static website using GitHub Pages. A free static host
does not provide a custom domain for free in every case, and does not add payment
processing. Ask a parent/guardian to help create and manage any hosting/payment accounts.
Do not publish personal contact details without guardian approval.

TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.
3. Add a product to the bag and try the demo order flow. The WhatsApp step will remain
   disabled until the store number is configured.

BEFORE ACCEPTING REAL ORDERS
A parent/guardian should review business eligibility, platform terms, privacy,
consumer-protection rules, taxes, shipping, returns and payment-provider requirements
for India and any countries you plan to serve.
